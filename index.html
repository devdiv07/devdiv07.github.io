PREFLIGHT

Stops recovery agents from asking customers who already paid to pay again.

An AI risk gate for payment-recovery agents, built for Razorpay AI Buildathon Track 02. The model identifies what must still be true. A live read of provider state checks it. Deterministic policy returns ALLOW, BLOCK or ESCALATE. ※ The first result was +0.556. A self-audit found a segmentation bug in the baseline. The corrected figure is +0.302 recall (0.889 vs 0.587), reported as a diagnostic, not a headline. PYTHON · RAZORPAY TEST MODE · POLICY ENGINE

02LIVE

Financial Operation Core

A timeout is not a failed refund.

Durable execution for money moves that agents start. A naive retry produces two refunds; this produces one. That holds through lost responses, crashed workers and 20 concurrent callers, measured in Razorpay Test Mode. The Chaos Lab lets you try to make it refund twice. PYTHON · IDEMPOTENCY · CHAOS TESTING
